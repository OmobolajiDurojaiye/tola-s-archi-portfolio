# tola-s-archi-portfolio

Architecture portfolio website for **Durojaiye Omotola Opeyemi**, 300-level B.Sc. Architecture student at Nile University of Nigeria, built for SIWES applications.

## Highlights
- Opening architectural piece-by-piece elevation assembly animation
- Interactive fanned studio card deck and rapid-skim 15-project index
- Custom glossy architectural cinema video player with cross-device H.264 walkthroughs
- Mixed-aspect masonry & studio plate viewer with full-screen lightbox zoom
- Interactive pixel architectural pavilion obsidian footer
- Mobile-first responsive design in Cream, Nude, and Black

## Scripts
```bash
npm install
npm run dev
npm run build
```
